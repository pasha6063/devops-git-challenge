# DevOps Git Challenge

## Project Description
This project demonstrates basic version control operations using Git and GitHub on Ubuntu. It covers creating files, managing branches, saving unfinished work, resolving merge conflicts, and collaborating through Pull Requests.

## Project Files
- `deploy.sh` — A sample Bash script for demonstrating deployment.
- `README.md` — Documentation about the project.
- `PROOF_OF_WORK.md` — Git commit history and reflection answers.

## Branches
- `main` — Contains the main project version.
- `development` — Used for development changes.
- `staging` — Used to demonstrate staging changes and merge conflicts.

## Git Operations
The practical includes repository cloning, commits, Git stash, branch merging, and Pull Request management.

## Purpose
The purpose of this repository is to practise Git workflows and understand how version control supports software development.
